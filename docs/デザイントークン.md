# デザイントークン

> マジックナンバー禁止。数値・色を直書きせず、必ず定数(`lib/core/constants/`)を経由する(TekuShareと同方針)。
> 実装: [app_colors.dart](../lib/core/constants/app_colors.dart), [app_spacing.dart](../lib/core/constants/app_spacing.dart), [app_sizes.dart](../lib/core/constants/app_sizes.dart), [map_constants.dart](../lib/core/constants/map_constants.dart)

## デザイン方針

- **トーン**: 不安を煽らない、落ち着いた「登山の相棒」のようなトーン。緊急感を出しすぎない配色・文言
- **視認性優先**: 屋外の強い日差しの下でも読みやすいコントラスト比を確保(WCAG AA相当: 4.5:1以上)
- **手袋着用時の操作性**: 主要ボタンは最低44×44pt(iOS)/ 48×48dp(Android)を確保

## カラー

| トークン名 | カラー | 用途 |
|---|---|---|
| primary | `#2E5339`(フォレストグリーン) | ボタン・アクティブ状態・山を連想させるメインカラー |
| primaryLight | `#A8C3AE` | 薄い緑・背景・チップ |
| primaryDark | `#1B3A22` | 押下状態 |
| warning | `#D97706`(アンバー) | 出没情報の警告表示。赤は過度に不安を煽るため避ける |
| danger | `#C0392B` | 緊急連絡(SOS)ボタン、およびエラー表示(赤文字・エラーダイアログ) |
| success | `#2E7D32` | 同期完了・保存成功等 |
| background | `#FAFAFA`(ライト)/ ダークモード対応 | 屋外の光量変化に対応 |
| surface | `#FFFFFF` | カード等 |
| textPrimary | `#212121` | 本文 |
| textSecondary | `#757575` | 補足テキスト |
| textDisabled | `#BDBDBD` | 無効状態 |

## スペーシング

`xs=4 / sm=8 / md=12 / lg=16 / xl=20 / x2l=24 / x3l=32 / x4l=40 / x5l=48 / x6l=64`

## コンポーネントサイズ

- buttonHeight: 52.0(グローブ着用時の操作性を考慮しTekuShareより大きめ)
- iconSm/Md/Lg: 16 / 24 / 32
- bottomNavHeight: 60.0 / appBarHeight: 56.0

## フォントサイズ

`xs=11 / sm=13 / md=15 / lg=17 / xl=20 / x2l=24 / x3l=32`(屋外使用を想定し本文は`md=15`ではなく`lg=17`以上を基本とする)

## フォントウェイト

`regular: w400 / medium: w500 / semiBold: w600 / bold: w700`

## 角丸(BorderRadius)

`xs=4 / sm=8 / md=12 / lg=16 / xl=24 / full=999`

## 地図定数

- defaultZoom: 15.0 / detailZoom: 17.0 / overviewZoom: 13.0
- gpsIntervalSec: 10(TekuShareの5秒より間隔を延ばし、山行中のバッテリー消費を抑制)
- defaultLat: 35.6895(東京)/ defaultLng: 139.6917(実際の登山エリアに応じて初期値を変更)

## 音声関連定数(本アプリ独自)

- defaultIntervalSec: 30(存在通知音の再生間隔デフォルト)
- minIntervalSec: 15 / maxIntervalSec: 120
- defaultVolume: 0.6(最大音量ではなく控えめな初期値)

## タイポグラフィ

- 見出し・本文ともに可読性の高いゴシック体(Noto Sans JP等)
- 屋外使用を想定し、本文最小サイズは17sp以上を推奨

## アイコン・イラスト

- クマのイラストは威圧的でなく、注意喚起として過度に恐怖を煽らないトーンで統一
- 出没情報ピンは「自治体公式データ」と「ユーザー投稿」を色・アイコンで明確に区別
